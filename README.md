# The 420 Lab 🌿🔬

An independent Discord bot for cannabis research education. This is not medical advice or a marketplace.

Initial foundation: PubMed evidence search, PubChem chemistry, ClinicalTrials.gov study discovery, optional Gemini synthesis, and private slash commands.

Run with Python 3.11+; see `requirements.txt`, `.env.example`, and `discloud.config` once the initial implementation is uploaded.

References: https://www.ncbi.nlm.nih.gov/books/NBK25499/ • https://pubchem.ncbi.nlm.nih.gov/docs/pug-rest • https://clinicaltrials.gov/data-api/api
