# Third-party dataset attribution

The file `data/strains.json` is a subset of the Kushy Cannabis Dataset (MIT), snapshot dated November 14, 2017. Selected fields: name, catalog type, breeder. The original includes unverifiable product efficacy and THC/CBD fields which are intentionally omitted. This reference is historical and not medical advice.

Original repository: https://github.com/kushyapp/cannabis-dataset
